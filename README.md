Ticket Generator & Journal System
Консольное приложение на C++ для автоматизированной генерации билетов и ведения детального журнала учета в формате .csv с полной поддержкой кириллицы и корректным отображением в Microsoft Excel.

📁 Структура проекта
Plaintext
ticket_generator/
│
├── Include/              # Заголовочные файлы (.h / .hpp)
├── src/                  # Исходный код реализации (.cpp)
├── build/                # Директория для сборки проекта (CMake)
├── journal.csv           # Журнал учета операций (формат CSV с UTF-8 BOM)
├── CMakeLists.txt        # Конфигурация сборки CMake
└── README.md             # Документация проекта
🚀 Требования для сборки
Компилятор C++ с поддержкой стандартов C++17 или выше (например, MinGW-w64 / GCC).

Система сборки CMake (версия 3.10 и выше).

🛠️ Инструкция по сборке и запуску
1. Сборка проекта через CMake
Откройте терминал в корневой папке проекта и выполните следующие команды:

Bash
mkdir build
cd build
cmake -G "MinGW Makefiles" ..
cmake --build .
2. Запуск программы
После успешной сборки исполняемый файл появится в папке build (или в корне проекта в зависимости от настроек). Запустить его можно командой:

Bash
# Из папки проекта
./build/ticket_generator.exe
📊 Особенности журнала учета (journal.csv)
Кодировка: UTF-8 с BOM (Byte Order Mark), что позволяет корректно открывать файл в Microsoft Excel без «кракозябр» и искажений кириллицы.

Разделитель: Точка с запятой (;), адаптированная под региональные стандарты Excel.

Структура данных: Все текстовые поля обернуты в кавычки для предотвращения смещения столбцов при наличии спецсимволов или запятых.
